# Contributing

This repository accepts contributions to **independent educational utilities**, documentation and tests for recipe portion calculations.

## Workflow
1. Open an issue explaining the proposed change.
2. Create a branch and add automated tests.
3. Submit a pull request with reproducible examples.

Do not submit personal health data, patient records, API keys, proprietary modules, or files from private repositories without explicit rights to publish them.

## Scope
This is not a medical device, clinical decision engine, or individualized nutrition prescription service. Calculations are illustrative and require professional validation for real-world use.
